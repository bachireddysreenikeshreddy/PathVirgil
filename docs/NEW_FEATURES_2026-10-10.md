# Harbor feature update — location, multilingual, air quality and reporting

## Changes
- On connected launch, request precise browser/device GPS permission once per session. Always offer a visible **Use my location** action. Fallback remains the labelled Mamallapuram pilot; no IP-location inference is presented as GPS.
- After GPS permission, the browser *may* send the current coordinates to BigDataCloud to display a city/region label. This is a client-side lookup allowed only for current, consented coordinates, and can fail without affecting GPS. Read its [policy](https://www.bigdatacloud.com/docs/article/why-is-reverse-geocoding-api-free) before public operation. Do not use it for stored coordinates or batch address lookup.
- Weather, 12h rain/wind forecast and air quality model values use the visitor's permitted coordinates. Open-Meteo/CAMS API supplies US AQI, PM2.5, PM10, ozone, NO2, SO2 and CO; values may be unavailable. **Pollutant values are µg/m³**, not individual health instructions or sensor measurements.
- Weather map opens on the visitor's position with a clear OpenStreetMap base layer. EUMETSAT satellite infrared imagery is **OFF by default**; users may turn it on. Satellite imagery is cloud-top temperature; it is not a street-level flood map.
- Official alert feed **remains restricted to the Mamallapuram pilot area**. Outside that area, the app explicitly warns it has no local official alert coverage. No flood/cyclone probabilities are fabricated; official agency alerts remain the authority.
- 15 language options (English, Hindi, Tamil, Telugu, Kannada, Malayalam, Bengali, Marathi, Gujarati, Punjabi, French, Spanish, German, Arabic and Japanese). **Only English, Hindi, Tamil and French retain full existing translations**. Added languages translate main navigation; remaining fields and safety guidance use clearly labelled English fallback. Do not claim complete translation.
- Nearby locations display available address and phone metadata, or explicitly "not verified". Most pilot map records have no verifiable telephone number or precise street address. **Never invent contact details**. Source-map links and national 112 remain available; do not treat any listed hospital as a guaranteed safe zone.
- Incident reporting hides raw lat/lon. The user must use GPS with consent or deliberately select a visibly approximate pilot location, and must enter a landmark. The server accepts the `other` category; its safety guidance is general, not flood-specific. Moderation remains required before community posts become public.

## Redeployment
This ZIP **does not update the live site or Android APK**. Extract over your local Harbor folder, retaining your own `wrangler.jsonc` with real D1 UUID. Do not copy the sample configuration over real bindings. Run `npm run offline:build` to regenerate cached resources and root index, `npm test` and `npm run typecheck`, then `npx wrangler pages deploy public --project-name pathvirgil --branch main`. Verify /api/health, /api/weather, /api/air-quality and no-photos report flow. For Android rebuild, use existing GitHub Actions after setting origin to https://pathvirgil.pages.dev.

## Privacy and security
Location is requested with browser permission; the user can deny it. Do not store precise location without the user's understanding (incident submissions deliberately contain incident position). Third-party map/geocode/weather endpoints will see relevant request information; reflect this in your privacy notice. Avoid using this app alone for emergency routing or risk prediction.
