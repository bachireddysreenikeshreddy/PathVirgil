# Submission checklist

The supplied rules require a GitHub repository, README, disclosure of open-source libraries/APIs, a 2–5 minute video in the repository, and accessible deployment. The project uses the TravelTech statement.

## Prepared

- Application source, persistent backend and migrations.
- README with problem, solution and setup.
- Dependency/API/model attribution.
- Automated tests and documented verification limits.
- Independent hosting configuration and deployment instructions.
- Android development APK source and reproducible build script; rebuild and test before submission.
- Evaluation mapping and judges' walkthrough.

## Requires the team

- Publish the source to the team's GitHub repository. Verify the GitHub repository contents and that the team controls the repository.
- Include the final hosted URL and APK link in that repository.
- Add team name and members if the submission form requests them.
- Record and add the required 2–5 minute demo video. Deferred by request, not waived by the hackathon.
- Team leader submits the required Google Form before the stated deadline.
- Verify the app on real Android/iOS devices before submission.

## Timing and disclosure

The rules state development during the hackathon window: 9 October 2026, 20:30 IST to 10 October 2026, 20:30 IST; submission before 21:00 IST on 10 October. Use real commit history and timestamps; do not backdate work.

The project uses open-source dependencies. Preserve accurate attribution, license notices, and any disclosures required by the event rules. Refer to the event's rules for any additional team-specific declaration.

## GitHub upload

Create a repository in the team's account, then upload the source archive contents or push from an extracted checkout. Keep credentials, .env files, node_modules, build caches and the development signing keystore out of version control. The Android output and bundled vendor assets are included in the downloadable project package.

No submission form, message to organizers, demo video or GitHub publication has been performed on the user's behalf.
